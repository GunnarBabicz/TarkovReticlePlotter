TARKOV BALLISTICS RETICLE PLOTTER

This is an application for Escape from Tarkov to give the user a graphical representation of ballistic drop, creating a rapid and convenient way of finding hold points at extended ranges

To activate the Python Environment, open a powershell or cmd window in this path. Perform the following steps to create the environment: 

1. Navigate to the path this folder is in using either Powershell or cmd
2. Create a virtual environment with the command "python -m venv [name you want for the virtual environment] 
3. Activate the virtual environment with .\[name you want for the virtual environemnt]\Scripts\Activate.ps1 in powershell. For cmd, the command will be .\[name you want for the virtual environemnt]\Scripts\Activate.bat
3. Install the required packages with the command pip install -r requirements.txt
4. To create a sample output, enter the command, "python run_in_command_line.py"
